
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória ao implementar uma versão jogável do clássico jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo em que o jogador tenta adivinhar uma palavra oculta, escolhendo uma letra por vez antes que as tentativas disponíveis acabem.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Solicitar palpites de uma letra e mostrar as letras corretas nas posições correspondentes, mantendo as demais ocultas (por exemplo, `_ _ _`).
- Atualizar e exibir o número de tentativas restantes após cada palpite incorreto.
- Encerrar a partida quando a palavra for adivinhada ou não houver mais tentativas.
- Exibir uma mensagem indicando vitória ou derrota; em caso de derrota, revelar a palavra escolhida.
